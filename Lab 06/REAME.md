# Operating Systems Lab 06 — Linux Command Line and File Management

In this lab, I practiced basic Linux commands using Ubuntu Terminal.

First, I used the `date` command to display the current date and time and the `cal` command to display the calendar. I also used `echo` to display a message, `whoami` to identify my username, `pwd` to display my current working directory, `ls -a` to list all files including hidden files, and `tty` to identify my terminal device.

Next, I created a main directory named `BS_Lab06` using the `mkdir` command and navigated into it using `cd`. Inside this directory, I created three subdirectories named `Documents`, `Reports`, and `Data`.

Finally, I created a text file named `student.txt` using the `touch` command. I used `echo` with output redirection to store my name, registration number, department, and semester in the file. I used the `cat` command to display and verify the stored information.

Through this practical, I learned how to use Linux commands for system information, directory navigation, folder creation, and file management.
