## Lab Objectives

The objectives of this lab are to:

1. Understand the process of installing Windows 10 using a bootable USB drive.
2. Perform a clean installation of Windows 10.
3. Customize the desktop theme and background.
4. Configure the taskbar and Start menu.
5. Adjust display settings for comfortable viewing.
6. Configure notification and privacy settings.
7. Demonstrate accessibility features available in Windows 10.

## Task 1: Windows 10 Installation Using a Bootable USB

### Requirements

- A USB flash drive (8 GB or larger, as used in the lab instructions).
- Windows 10 ISO file downloaded from Microsoft's official website.
- Rufus software to create a bootable USB.
- A computer compatible with Windows 10.

### Installation Procedure

1. Prepare the bootable USB using the Windows 10 ISO file and Rufus.
2. Restart the computer and open the boot menu.
3. Select the USB storage device to start Windows Setup.
4. Select the language, time and currency format, and keyboard layout.
5. Click **Install now**.
6. Accept the Microsoft Software License Terms.
7. Select **Custom: Install Windows only (advanced)** for a clean installation.
8. Identify the correct drive partition for Windows installation.
9. Wait while Windows copies files and installs the required features.
10. Enter the desired user account name.
11. Configure the initial setup options, including network settings.
12. Wait for Windows to complete its configuration and start.
13. Check that the Windows desktop appears successfully.

### Precautions

- Back up important files before starting a clean installation.
- Verify the target partition carefully before formatting or deleting anything.
- Do not turn off the computer during installation.
- Use a valid Windows license for activation.

## Task 2: Practical Customization of Windows 10

### 1. Desktop Theme and Background

- Open **Personalize** by right-clicking the desktop.
- Open the Background section and choose a picture.
- Browse and select a suitable background image.
- Choose an appropriate image fit option.
- Open Themes and select a matching theme.
- Verify the changes on the desktop.

### 2. Taskbar and Start Menu

- Open **Taskbar settings** by right-clicking the taskbar.
- Review and adjust the available taskbar options.
- Navigate to **Settings → Personalization → Start**.
- Review the available Start menu options.
- Open the Start menu and verify the changes.

### 3. Display Settings

- Right-click the desktop and select **Display settings**.
- Check the display resolution under Scale and layout.
- Select the recommended resolution when available.
- Adjust text and application scaling if needed.
- Review the Night light option.
- Confirm that text and icons are comfortable to view.

### 4. Notification and Privacy Settings

- Open **Settings → System → Notifications & actions**.
- Review notification settings.
- Turn off unnecessary application notifications where appropriate.
- Keep important security and system notifications enabled.
- Open **Settings → Privacy**.
- Review permissions for location, camera, and microphone.
- Disable unnecessary application access where appropriate.

### 5. Accessibility Features

#### Magnifier

1. Press **Windows key + Plus (+)** to open Magnifier.
2. Use Windows key + Plus (+) to zoom in.
3. Use Windows key + Minus (-) to zoom out.
4. Observe how Magnifier enlarges screen content.
5. Close Magnifier after testing.

#### On-Screen Keyboard

1. Press **Windows key + Ctrl + O** to open the On-Screen Keyboard.
2. Alternatively, open the keyboard accessibility settings.
3. Click the displayed keys using the mouse to enter text.
4. Close the On-Screen Keyboard after testing.
