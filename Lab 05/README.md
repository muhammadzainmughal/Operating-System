# Operating Systems Lab 05 — Linux Installation and GUI Exploration Using VMware

In this lab, I installed and configured VMware Workstation on my computer. I downloaded the Ubuntu Linux ISO file and created a new virtual machine.

I allocated 4 GB of RAM, 25 GB of virtual disk space, and 2 processor cores to the virtual machine. After configuring the settings, I installed Ubuntu Linux and created my user account.

I explored the Ubuntu desktop environment, application menu, File Manager, web browser, System Settings, and Terminal. I also created a folder named `BS_Linux_Lab` using File Manager.

Finally, I opened Terminal and used the `whoami` command to identify my logged-in username. I then properly shut down the Ubuntu virtual machine.

Through this practical, I learned how to install Linux in a virtual environment and explore its graphical user interface.
